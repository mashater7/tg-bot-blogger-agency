# Telegram-бот рекламного агентства для блогеров

Разбор ТЗ и интерактивный прототип: как будет работать Telegram-бот для блогеров и веб-панель для менеджеров.

**Открыть страницу:** https://mashater7.github.io/tg-bot-blogger-agency/

**Короткая версия:** https://mashater7.github.io/tg-bot-blogger-agency/short/

На странице:
- простая схема «дорожка от подарка до поста»;
- живой прототип: Telegram блогера и панель менеджера работают вместе;
- пути пользователей по ролям и дерево решений;
- ограничения Telegram Bot API (сверено с документацией, версия 10.3);
- этапы работ и вопросы заказчику.

Это черновик для обсуждения, а не работающий бот. Имена, бренды и цифры выдуманы для примера.

## Интерактивное демо iPhone

Полная и короткая страницы используют общие `assets/iphone-demo.js` и `assets/iphone-demo.css`. Меню, разделы блогера, ввод, вложения-образцы и навигация менеджера работают локально. Сценарии товара и ресторана сохраняют независимый прогресс до перезагрузки вкладки. «Начать заново» сбрасывает выбранный сценарий.

Для локального просмотра из корня репозитория: `python -m http.server 8769 --bind 127.0.0.1`, затем открыть `http://127.0.0.1:8769/short/#try`. Сборки и установки зависимостей нет. Демо не отправляет сообщения в Telegram и не хранит данные на сервере; CSV содержит вымышленные данные.
